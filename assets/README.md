# assets/

Moddable text data. A scenario is built from these files once (parsing and
calibration, `src/sim/scenario.cpp`), then saved as a DCON binary
(`geosim_headless build ... --out scenario.bin`) so later starts skip parsing.

```
assets/
  SOURCES.txt                    provenance + licences (generated)
  map/world.gsmap                world map: region-ID raster, relief, climate (generated by
                                 tools/pipeline/build_map.py; docs/07-map-and-filters.md)
  defs/                          hand-written model definitions
    parameters.txt               every global parameter (name{value} # description and source)
    npi.txt                      non-pharmaceutical interventions (OxCGRT indicators)
    sectors.txt                  sectors incl. input-output coefficients, critical inputs, input stocks, subsistence
    pathogens.txt                pathogens incl. vaccines and emergent templates
    sea_lanes.txt                shipping network: sea nodes, lanes, chokepoints (hazards, littoral states)
    commodities.txt              non-oil commodity markets (gas, coal, grains, metals)
    technologies.txt             diffusing technologies (EVs, renewables, AI services, 5G, mRNA)
    organisations.txt            international organisations: kind, decision rule, seats, terms
    names.csv                    people's names per culture (English spellings) for the in-game internet
    name_cultures.csv            which cultures each identity group / nation uses (weights mix them)
    tlds.csv                     internet domains per nation: ccTLD and co.uk / gov.uk / org.uk / ac.uk-style suffixes
    nation_names.csv             common English names of nations shown in the UI (South Korea, DR Congo)
    web_text.csv                 the in-game internet's text pools: social posts by style, usernames, torrent titles
    flags.csv                    national flags as vector elements (stripes, stars, crescents, emblems; docs/08-ui.md#flags)
    flag_emblems.csv             the flags' shared pool of low-poly emblems (shields, eagles, crowns, ...)
  scenario/2020/
    nations.csv                  macro state per nation, 2019 data (generated)
    sectors.csv                  value-added / employment shares per nation x sector (generated)
    nations_curated.csv          hand-written per-nation values and gap fills (sources in header)
    finance_curated.csv          banking, credit, bonds, CPI basket, coordination, tariffs, unions, taxes
    society_curated.csv          youth, social media, corruption, emigration, net freedom, trust
    groups_curated.csv           identity groups (caste, race, hukou, migrant status)
    parties_curated.csv          party systems (expert-survey positions, last election, cabinet)
    politics_curated.csv         electoral systems, calendars, veto players, defence spending
    ports_curated.csv            sea nodes of each nation's ports (shares)
    logistics_curated.csv        port throughput, seaborne share of trade
    overland_curated.csv         overland share of bilateral trade (contiguity)
    commodities_curated.csv      commodity production / consumption shares
    monetary_curated.csv         currency unions, pegs, reserve-currency shares
    relations_curated.csv        alliances, tariffs and sanctions at the start
    conflict_curated.csv         nuclear arsenals (SIPRI 2020)
    rivalries_curated.csv        strategic rivalries (Thompson & Dreyer 2012)
    technology_curated.csv       observed 2019 technology adoption
    organisations_curated.csv    memberships: organisation, nation (ALL = every nation), role, term end, exit
    nations_ext_curated.csv      R&D, reserves, decentralisation, terrain, term limits, language, religion
    Every *_curated table is optional: nations without rows use documented defaults.
  scenario/world2020/            full world (generated by tools/pipeline/build_world.py)
    scenario.txt                 base{2020}: curated tables missing here are inherited from scenario/2020,
                                 and layered tables read generated -> 2020 curated -> own curated
    nations.csv, sectors.csv     218 nations (WDI; Fiscal Space debt/balance; WHO beds; income-group imputation)
    states.csv                   3,240 states: geoBoundaries ADM1 (+ Natural Earth for the French overseas
                                 regions); the legal level (governors, district seats, redrawable)
    regions.csv, adjacency.csv   11,898 regions: clusters of counties inside each state, sized by population
                                 (GHS-POP 2020; tools/pipeline/adm2.py), and their adjacency; sector mixes
                                 and GDP shares are derived at load (scenario.cpp derive_region_sectors)
    adm2.csv                     49,570 counties (geoBoundaries ADM2; a state without ADM2 data is one) and
                                 their cluster: drawn by the map (world.gsmap polygons), simulated as clusters
    society.csv, finance.csv, nations_ext.csv, logistics.csv   generated from WDI, WGI, GFDD, Fiscal Space,
                                 ILOSTAT, TI CPI, UN DESA, Nunn-Puga, CLDR (tools/pipeline/world_extra.py)
    nations_curated.csv, nations_extra_curated.csv   hand-written values; non-WB nations (Taiwan)
    parties_curated.csv, politics_curated.csv        party systems and institutions of 172 nations
    monetary_curated.csv         euro area, CFA franc zones, ECCU, pegs and dollarisation (IMF AREAER 2019)
    commodities_curated.csv      world commodity shares
    jurisdictions_curated.csv    dependent jurisdictions: sovereign and autonomy (HKG, MAC, PRI, ...)
    claims_curated.csv, claims.csv   territorial claims; claims.csv only when the pipeline finds boundary
                                 duplicates not already curated (none in the current build)
  scenario/2008/                 2008 calibration slice (tools/pipeline/build_slice2008.py; in progress)
  events/2020/                   dated events; every *.txt file is loaded, in name order

    2020_brent.csv               daily Brent 2020 (generated)

    2020_targets_curated.csv     hand-written targets: 10-year yields, credit growth
    world2020_targets.csv, world2020_tolerances.txt   full-world targets and bands
    2008_targets.csv, 2008_y2_targets.csv, 2008_brent.csv   2008 and 2009 outcomes (generated)
```

**Generated** files are written by `tools/pipeline/build_assets.py` from raw
downloads (`tools/pipeline/fetch.py` -> `data/raw/`, not committed). Edit the
pipeline, or override values in the `*_curated` files, rather than editing
generated files by hand: a rebuild overwrites them.

```sh
python3 tools/pipeline/fetch.py          # download (cached in data/raw/)
python3 tools/pipeline/build_assets.py   # regenerate assets/
```

## Formats

**CSV**: first non-`#` line is the header; `#` lines are comments; empty
field = missing (the loader uses a documented default and prints a warning).

**Definitions** (`.txt`): the same brace syntax as DCON schema files, plus
`#` comments.

```
key{ value }                       # leaf
key{ child{ value } other{ x } }   # node
```

## Event kinds (`assets/events/<scenario>/*.txt`)

Every event has `date{YYYY-MM-DD}` and `nation{ISO3}` (`ROW` = rest of world).
Policy kinds are applied only when `historical_anchors{1}` (the default).

| Kind | Fields | Effect |
|------|--------|--------|
| `npi` | `indicator{C1..H6}` `level{x}` `targeted{0..1}` | sets an NPI level; `targeted` = regional share (OxCGRT `_Flag = 0`) |
| `policy_rate` | `rate_pct{x}` | sets the central-bank policy rate |
| `fiscal_package` | `pct_gdp{x}` | adds a package (% of 2019 GDP); it funds crisis programmes first, the rest is disbursed |
| `stw` | `coverage{0..1}` `replacement{0..1}` | job-retention scheme: share of jobs kept on reduced hours, wage share paid |
| `test_trace_isolate` | `strength{0..1}` | suppression strategy: mass testing, centralised isolation, arrival quarantine |
| `epidemic_seed` | `infections{n}` | adds latent infections (exogenous; always applied) |
| `oil_production` | `mbd{x}` | absolute crude production target (exogenous) |
| `oil_production_delta` | `mbd{x}` | change of production target (exogenous) |
| `house_price_shock` | `change{x}` | multiplies national and regional house prices by 1 + x (e.g. -0.2; exogenous) |
| `equity_shock` | `change{x}` | multiplies the equity price by 1 + x (exogenous) |
| `credit_spread_shock` | `pp{x}` `unwind_days{n}` | adds x pp to the lending spread; it decays at rate 1/n per day (0 or absent = persistent; exogenous) |
| `bank_capital_shock` | `pp{x}` | cuts the bank capital ratio by x pp (losses on securities; capital falls by x% of risk-weighted loans; exogenous) |

The financial shocks are historical anchors for crises (the 2008 slice): wealth
effects (`assets.cpp`) and lending (`credit.cpp`) propagate them. They act
directly, whatever `historical_anchors` is.

Any field not listed (e.g. `source{...}`) is ignored by the loader and is the
place to cite where a hand-written value comes from.
