# node{ key lat lon }            a representative port / basin hub (keys up to 4 characters)
# lane{ a b nm [chokepoint] }    sailing distance between two nodes in nautical miles (both
#                                directions). Distances are rounded port-to-port sea distances
#                                (sea-distances.org / Lloyd's distance tables); a lane through a
#                                strait or canal names its chokepoint.
# chokepoint{ ... }              a narrow passage whose capacity can fall:
#   capacity          transits per day the passage can handle when fully open
#   traffic           transits per day in 2019
#   canal_days        extra time of the passage itself (convoys, pilots, locks)
#   incident_rate     blocking incidents per year at 2019 traffic and vessel size
#   incident_cut      share of capacity lost in an incident (1 = closed)
#   size_elasticity   hazard elasticity to mean vessel size (larger ships ground more easily
#                     and catch more wind; Merk 2015, ITF "The impact of mega-ships")
#   duration_median / duration_sigma   lognormal duration of an incident (days)
#   season_amp / season_peak           seasonal hazard amplitude and peak day of year (winds, fog)
#   drought_rate / drought_cut / drought_days   capacity cut from low water (Panama locks)
#   littoral{ ISO3 ... }   nations whose wars or unrest can close the passage (unknown ISO3
#                          codes are ignored, so the list also serves the full-world scenario)
#
# Calibration notes:
#  SUE  Suez Canal Authority: 18,880 transits in 2019 (52/day); about 120/day were handled
#       while the queue cleared after the Ever Given refloat (2021-03-29). Multi-day full
#       blockages by grounding: Tropic Brilliance (2004, ~3 days), Ever Given (2021, 6 days)
#       -> about 0.1 per year. Spring khamsin winds raise the hazard (peak late March).
#  PAN  Panama Canal Authority FY2019: 13,785 transits (~36 ocean-going/day); drought draft
#       restrictions in 2016, 2019-20 and a severe one in 2023 (El Nino) -> ~0.15 per year,
#       capacity cut ~30% for ~5 months.
#  BOS  Turkish Straits: ~42,000 transits a year; short suspensions for fog and breakdowns
#       are frequent (several a year, hours long).
#  MAL / HOR / BAB / GIB / TWN: wide straits, never fully closed by accidents; their risk is
#       conflict (tanker war 1984-88, Red Sea attacks 2023-24) via littoral nations.
