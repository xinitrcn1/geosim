# Production sectors (hand-written; moddable).
#
# key           matches assets/scenario/<year>/sectors.csv
# role          generic | government | energy | contact | manufacturing (see src/sim/model.hpp)
# labor_share   compensation of employees / value added (OECD national accounts, rounded)
# oil_intensity relative oil use per unit of output (transport-heavy services highest)
# import_intensity relative import content per unit of output (goods >> services; OECD TiVA, rounded)
# voluntary_distancing  1 = demand falls when people avoid contact (Goolsbee & Syverson 2021)
# demand        prior share of each final-demand component (hh, gov, inv, exp) landing in this
#               sector. The loader rescales them (RAS) so baseline sector value added matches data.
# skills        employment mix by skill tier (low, mid, high); ILO/OECD occupation data, rounded
# npi_capacity  capacity lost at the maximum level of each OxCGRT indicator (summed, capped at 95%).
#               Contact services lose ~58% at every indicator's maximum, in line with the deepest
#               observed 2020 hospitality/retail/transport output falls.
#               Informed by Dingel & Neiman (2020) teleworkability and del Rio-Chanona et al. (2020)
#               supply-shock estimates by industry.
#
# Input-output (Leontief 1936; Miller & Blair 2009), used by the dynamic production
# network in src/sim/systems/economy.cpp (after Pichler, Pangallo, del Rio-Chanona,
# Lafond & Farmer 2022, "Forecasting the propagation of pandemic shocks with a dynamic
# input-output model", JEDC):
# inputs{ s{a} }  technical coefficients: input from sector s per unit of this sector's
#               gross output (domestic + imported). Rounded world averages of the OECD
#               Input-Output Tables 2018 edition aggregated to these 7 sectors (Timmer et
#               al. 2015 WIOD gives similar values). Gross output = value added / (1 - sum).
# critical_input  1 = a shortage of this sector's output stops downstream production
#               (Leontief); 0 = downstream can carry on without it for weeks (services).
#               Pichler et al. (2022) use IHS Markit criticality ratings; goods and energy
#               are critical for nearly every industry, most business services are not.
# inventory_days  stock of inputs held, in days of use (Pichler et al. 2022, Table 2,
#               rounded: manufacturing ~ 3-4 weeks, services ~ 1 week).
# shipped       1 = output crosses borders in ships and containers (goods), uses ports
#               and the container fleet (src/sim/systems/logistics.cpp).
