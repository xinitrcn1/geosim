# 08 — UI

## Principles

The interface looks like a statistics office's internal tool: plain, dense,
honest. Every pixel either shows data or lets the player act.

- **One typeface**, a neutral sans (e.g. Inter or Noto Sans for script
  coverage), in 3 sizes (12/14/18 px at 1× scale). Tabular (monospaced)
  figures for numbers. Shaped with HarfBuzz, rasterised with FreeType.
- **Palette:** greys + **one** accent colour (selection, focus, primary
  button) + semantic red/green used *only* for signed deltas, plus
  colour-blind-safe alternates. Map colours follow [07](07-map-and-filters.md).
- **No decoration:** no textures, gradients, drop shadows, bevels, icons for
  their own sake, or splash art. 1 px borders. Flat rectangles.
- **Motion:** none, except ≤ 100 ms fades for appearing panels and tooltips.
- **Numbers always carry units**, plus the date and source/model when
  ambiguous ("Unemployment 7.4 % · ILO def. · 2020-06").
- **Keyboard first:** every action reachable by keyboard. A command palette
  (`Ctrl+K`) searches regions, nations, agents, policies, filters.
- **Scaling:** UI scale 1×–3×, following SDL3 display content scale.
- Localisable from day one (HarfBuzz shaping, UTF-8 strings, RTL-capable layout).

## Layout

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 2020-03-14  ▶▶ 3   │ Alerts (3) │ Overrides: ITA exec, ITA CB │  Ctrl+K   │  top bar
├──────────────┬─────────────────────────────────────────┬───────────────────┤
│ FILTERS      │                                         │ INSPECTOR         │
│ Economy      │                                         │ Lombardy (ITA)    │
│  ▸ Unemploy. │                                         │ Pop 10.0 M        │
│  ▸ Inflation │                MAP                      │ Unemp 9.1% (+3.2) │
│ Inequality   │                                         │ ─ sparkline ─     │
│ Society      │                                         │ Strata ▾          │
│ ...          │                                         │ Agents ▾          │
│ Mode: Δ 03-01│                               [legend]  │ [Why?]            │
├──────────────┴─────────────────────────────────────────┴───────────────────┤
│ Journal │ Trace │ Charts │ Ledger │ Diplomacy                                │  bottom drawer
└────────────────────────────────────────────────────────────────────────────┘
```

- **Top bar:** date, speed, pause state, alerts count (click → list), active
  overrides (click → manage), command palette.
- **Left (filters):** filter tree, display mode selector, stratum lens, reference date.
- **Right (inspector):** context-sensitive. For a region: key indicators with
  Δ and sparkline, the strata table, the agents acting on it. For an agent:
  powers, current intent with its utility breakdown, and override controls.
- **Bottom drawer (tabs):**
  - *Journal*: decisions (player + AI), with scheduled reviews.
  - *Trace*: the "Why?" decomposition tree ([01](01-gameplay-loop.md#51-the-why-trace-always-on-cheap)).
  - *Charts*: time series, any indicator, compare regions/nations/forks.
  - *Ledger*: the SFC matrices for the selected nation (the full transparency view).
  - *Diplomacy*: relations matrix, treaties, negotiations in progress.

## Interaction patterns

- **Hover** any number → tooltip with definition, unit, source/model, last update tick.
- **Click** any number → opens it in the Trace tab.
- **Shift+click** regions → multi-select, comparisons appear in Charts.
- **Override flow:** inspector → agent → *Advise / Direct / Force* → a policy
  editor showing the current value, the AI's preferred value and the
  player's value, with a static incidence estimate per stratum → *Commit*
  (applied at the next tick).
- **Tables:** sortable, filterable, copy to clipboard as TSV (players will
  want to analyse data in spreadsheets).

## Implementation

- Custom **immediate-mode** UI on top of our own Vulkan 2D batch renderer
  (rectangles, lines, glyph quads from a FreeType glyph atlas). Layout is a
  simple row/column/flex model computed each frame.
- Dear ImGui may be used **only** for developer debug overlays behind a
  compile-time option. It does not ship in the player UI.
- The UI reads only from the **sim snapshot** ([09](09-engine-architecture.md#threading))
  and writes only through the **command queue**. It never touches the live sim state.
